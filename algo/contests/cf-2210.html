B

Let's say that the optimal sequence of operations results in us stopping at position 𝑖i.

Then it's optimal to have sat at all chairs 𝑗j behind us such that either 𝑝𝑗 ≤𝑗pj≤j or 𝑖 ≤𝑝𝑗i≤pj. The first category doesn't prevent us from going forward at all (as they mark chairs behind or at our current position), and the second category won't prevent us from reaching 𝑖i.

The optimal score for every stopping point can therefore be computed by iterating over 𝑖i in increasing order, and using either a std::set or a range query DS.

C1

Notice that the condition:

gcd⁡(𝑎𝑙,𝑎𝑙+1,…,𝑎𝑟) =gcd⁡(𝑎′𝑙,𝑎′𝑙+1,…,𝑎′𝑟)gcd⁡(al,al+1,…,ar)=gcd⁡(al′,al+1′,…,ar′) for all 1 ≤𝑙 <𝑟 ≤𝑛1≤l<r≤n

is equivalent to

gcd⁡(𝑎𝑖,𝑎𝑖+1) =gcd⁡(𝑎′𝑖,𝑎′𝑖+1)gcd⁡(ai,ai+1)=gcd⁡(ai′,ai+1′) for all 1 ≤𝑖 <𝑛1≤i<n

Now, for a particular 1 <𝑖 <𝑛1<i<n, its value in the second array, 𝑎′𝑖ai′ only matters to two conditions:

  1. gcd⁡(𝑎𝑖,𝑎𝑖−1) =gcd⁡(𝑎′𝑖,𝑎′𝑖−1)gcd⁡(ai,ai−1)=gcd⁡(ai′,ai−1′)
  2. gcd⁡(𝑎𝑖,𝑎𝑖+1) =gcd⁡(𝑎′𝑖,𝑎′𝑖+1)gcd⁡(ai,ai+1)=gcd⁡(ai′,ai+1′)

We notice that 𝑎′𝑖ai′ must therefore be divisible by 𝑐𝑖 =lcm⁡(gcd⁡(𝑎𝑖,𝑎𝑖−1),gcd⁡(𝑎𝑖,𝑎𝑖+1))ci=lcm⁡(gcd⁡(ai,ai−1),gcd⁡(ai,ai+1)).

𝑐𝑖ci is also the smallest value for 𝑎′𝑖ai′ that satisfies both these conditions (at least from 𝑖i's side).

If 𝑐𝑖 <𝑎𝑖 =𝑏𝑖ci<ai=bi, we simply set 𝑎′𝑖 =𝑐𝑖ai′=ci, and this increases our score by 1.

Otherwise, we have 𝑐𝑖 =𝑎𝑖ci=ai. In this case:

  1. We cannot set 𝑎′𝑖ai′ to anything less than 𝑐𝑖ci, as we have shown 𝑐𝑖ci to be the smallest valid value of 𝑐𝑖ci.
  2. We cannot set 𝑎′𝑖ai′ to any other multiple of 𝑐𝑖ci as 𝑐𝑖 =𝑎𝑖 =𝑏𝑖ci=ai=bi.

Therefore, we are forced to set 𝑎′𝑖 =𝑎𝑖ai′=ai (not make a move).

C2

The harder version decouples 𝑎𝑖ai and 𝑏𝑖bi.

This only affects our previous analysis at one place: previously, when we had 𝑐𝑖 =𝑎𝑖ci=ai, in point 2, we argued that we cannot set 𝑎′𝑖ai′ to some non-trivial multiple of 𝑐𝑖ci, as we had 𝑐𝑖 =𝑎𝑖 =𝑏𝑖ci=ai=bi.

But now, we can have 𝑎𝑖 <𝑏𝑖ai<bi, which will allow us to set 𝑎′𝑖 =𝑚𝑖 ⋅𝑐𝑖ai′=mi⋅ci (where 𝑚𝑖 >1mi>1).

Lemma 1:

There exists an optimal solution wherein the chosen 𝑚𝑖mi for all 𝑖i at which we set 𝑎′𝑖 =𝑚𝑖 ⋅𝑐𝑖ai′=mi⋅ci (𝑚𝑖 >1mi>1) is prime.

Proof: easy enough to show, but left as an exercise to the reader.

Lemma 2:

There exists an optimal solution wherein the set of used 𝑚𝑖mi is a subset of the first 𝑃 =25P=25 primes.

Proof: left as an exercise to the reader (hint: 𝑚𝑖mi is only restricted by 𝑚𝑖−1,𝑎𝑖−1,𝑐𝑖,𝑚𝑖+1,𝑎𝑖+1mi−1,ai−1,ci,mi+1,ai+1, and any number up to 10181018 cannot have too many distinct prime factors).

We can therefore do a dynamic programming with the following state:

  • 𝑓(𝑖)f(i) = maximum number of moves we can make in the prefix 𝑖i, if we make no move at position 𝑖i.
  • 𝑔(𝑖,𝑥)g(i,x) = maximum number of moves we can make in the prefix 𝑖i, if we set 𝑎′𝑖 =𝑐𝑖 ⋅𝑝𝑥ai′=ci⋅px (where 𝑝𝑥px is the 𝑥x-th smallest prime).

D

Firstly, let 𝑓(𝑠)f(s) be the maximum 𝑥 ≤𝑛/2x≤n/2 such that for all 𝑖 ≤𝑥i≤x, 𝑠𝑖si gets matched to 𝑠𝑛−𝑖+1sn−i+1 by RBS rules.

Lemma 1:

𝑓(𝑠) =𝑓(𝑡)f(s)=f(t) is a necessary requirement for 𝑠s and 𝑡t to be interconvertible, as 𝑓(𝑠) =𝑓(𝑠′)f(s)=f(s′) after any operation that converts 𝑠s to 𝑠′s′

Proof: Exercise for the reader (hint: this outer section can never be modified by any operation).

If 𝑓(𝑠) ≠𝑓(𝑡)f(s)≠f(t), we're done. Otherwise, we get rid of the first and last 𝑓(𝑠)f(s) characters from both 𝑠s and 𝑡t.

Now, consider the RBS trees 𝑇(𝑠)T(s) and 𝑇(𝑡)T(t) built from 𝑠s and 𝑡t (note that since we removed the first/last 𝑓(𝑠)f(s) characters, these trees will either be empty, or the root will have > 1 child).

The equivalent problem on these trees is the following:

You can perform any number of the following operations on either tree:

Select nodes 𝑢u and 𝑣v such that neither is an ancestor of the either, and attach some "adjacent" children of 𝑣v (in the ordered child sequence) to the parent of 𝑢u, and attach 𝑣v to 𝑢u.

Can the two trees be made isomorphic?

Now, notice the following invariant: The number of leaf nodes remains the same after every operation.

While obviously necessary, it turns out that having an equal number of leaf nodes is sufficient for two trees to be interconvertible.

Proof:

Let's say a tree has 𝑙l leaves.

Regardless of the initial structure of the tree, we can always convert it to the following equivalence class representative:

A tree with 𝑙 −1l−1 leaves hanging from the root, and a chain containing the remaining nodes.

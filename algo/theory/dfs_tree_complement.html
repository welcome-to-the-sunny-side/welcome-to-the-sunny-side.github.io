Traversing complement graphs using DFS Trees

11/19/2026(.md)

  • algorithm

Prerequisite: DFS-Trees

Consider the following problem:

Given a graph 𝐺(𝑉,𝐸)G(V,E) on 𝑛n nodes, find a simple path with at least 𝑛/2n/2 nodes in either 𝐺G or its complement 𝐺′G′.

Let's ask ourselves a dumb question: Given some simple path 𝑃P in 𝐺G, can we find a simple path 𝑃′P′ in 𝐺′G′ that contains every node that's not in 𝑃P?

If this was possible for any path 𝑃P, then at least one of 𝑃P or 𝑃′P′ would satisfy our requirements, as max(|𝑃|,|𝑃′|) =max(|𝑃|,𝑛 −|𝑃|) ≥𝑛/2max(|P|,|P′|)=max(|P|,n−|P|)≥n/2.

There can of course be exponentially many paths 𝑃P in 𝐺G, so we restrict our analysis to a convenient subset of paths. Let's construct some "DFS-Forest" 𝐹F of 𝐺G (a DFS-Tree for every connected component). In fact, let's simplify our analysis even further for the moment, and assume that 𝐺G is connected, so it yields just one DFS-Tree.

Now, consider paths 𝑃P from the root 𝑟r to some node 𝑙l. This simple path clearly exists in 𝐺G, but what about 𝑃′P′? Can we somehow chain together nodes that don't lie in 𝑃P into a simple path?

The DFS-Tree, along with 𝑃P can be visualised in the above manner. Can we think of some connection between DFS-trees and complement graphs that would allow us to chain together the red nodes to construct 𝑃′P′?

If you've read the blog I've linked at the top, the following observation will seem fairly natural:

Lemma 1

Neither 𝑢u nor 𝑣v is an ancestor of the other in 𝐹F ⟹ ⟹ edge (𝑢,𝑣)(u,v) exists in 𝐺′G′.

Now consider the subtrees 𝑠1,𝑠2,…𝑠𝑘s1,s2,…sk hanging off 𝑃P. The above observation implies that there's an edge in 𝐺′G′ between every pair of nodes that belong to different subtrees!

Therefore, one (of possibly many) way to construct a path in 𝐺′G′ that visits every node in 𝑆 =𝑠1 ∪𝑠2 ∪⋯ ∪𝑠𝑘S=s1∪s2∪⋯∪sk could be to start at some node outside 𝑃P, and then repeatedly jump to a previously unvisited node that lies in a different hanging subtree from the current one.

What condition on 𝑠1,𝑠2,…𝑠𝑘s1,s2,…sk will allow us to always construct 𝑃′P′ in such a manner? We just want max(|𝑠𝑖|) ≤⌈|𝑆|2⌉max(|si|)≤⌈|S|2⌉!

But wait a minute, does there always exist a 𝑃P such that the induced 𝑠1,𝑠2,…𝑠𝑘s1,s2,…sk satisfy this property?

Lemma 2

For any rooted tree, we can always find a path 𝑃P starting at the root such that the induced 𝑠1,𝑠2,…𝑠𝑘s1,s2,…sk satisfy max(|𝑠𝑖|) ≤⌈|𝑆|2⌉max(|si|)≤⌈|S|2⌉.

Proof

Denote the path between 𝑟r and 𝑙l by 𝑃P, and 𝑆 =𝑉 ∖𝑃S=V∖P.

Let's start at the root, with 𝑙 =𝑟l=r. If this path satisfies the required condition, then we're done. But what if it doesn't? This would mean that exactly one child 𝑐c of 𝑙l has a subtree of size >⌈|𝑆|2⌉>⌈|S|2⌉.

Clearly, any valid 𝑙l must lie in the subtree of 𝑐c, as any other choice would result in the hanging subtree of 𝑐c having >⌈|𝑆|2⌉>⌈|S|2⌉ nodes. We then set 𝑙 =𝑐l=c and recursively continue (𝑃P and 𝑆S are updated). At every step, if there's some child of 𝑙l with subtree-size >⌈|𝑆|2⌉>⌈|S|2⌉, we're forced to place 𝑙l somewhere in its subtree. Since we'll eventually hit a leaf (which has no children), we're guaranteed to reach a node 𝑙l where there's no "dominant" child. Note that whenever we're at a node with a dominant child, no induced hanging subtree outside the subtree of the current node can be dominant.

When we reach such a node 𝑙l, can there be some dominant 𝑠𝑖si induced outside 𝑙l's subtree? Let 𝑝p be the parent of 𝑙l, and 𝑥x be the subtree size of 𝑙l. Since 𝑝p doesn't satisfy the condition, we must have 𝑥 >⌈(|𝑆|+1)2⌉x>⌈(|S|+1)2⌉. This implies that the maximum possible size of any hanging-subtree outside the subtree of 𝑙l is ≤⌈|𝑆|2⌉≤⌈|S|2⌉.

Hence, 𝑙l must be valid.

So, that's it. You find 𝑙l such that the path 𝑃P from 𝑟r to 𝑙l satisfies this property. If |𝑃| ≥𝑛/2|P|≥n/2, you're done. Otherwise, you can just construct a path from the hanging subtrees.

The observant reader will now exclaim, "[user:DNR,2026-11-18]! Your analysis holds only under the assumption that 𝐺G is connected (so 𝐹F has only one DFS-tree)!"

First, notice that Lemma 1 holds for arbitrary DFS-forests, so if we pick a rooted path in some DFS tree in 𝐹F, then we can treat any other tree as an induced subtree 𝑠𝑖si too! But what about lemma 2? We did need it to guarantee the existence of 𝑙l.... Can we get an analogous lemma for DFS-forests?

Lemma 3

For any rooted forest, we can always find a path 𝑃P starting at some root such that the induced 𝑠1,𝑠2,…𝑠𝑘s1,s2,…sk satisfy max(|𝑠𝑖|) ≤⌈|𝑆|2⌉max(|si|)≤⌈|S|2⌉.

Proof

Construct the DFS-forest, and then add a "virtual root node" which has all the other roots as children.

The argument we used for Lemma 2 works out again.

Therefore, we've solved the problem. It's easy to implement this solution in 𝑂(𝑛 +𝑚)O(n+m).

More

The blog was inspired by the following problem, and one may realise that we have solved it:

Given a graph 𝐺(𝑉,𝐸)G(V,E) on 𝑛n nodes, find a Hamiltonian path that first only uses edges in 𝐺G, and then only uses edges in 𝐺′G′.

The only additional observation that we need (after finding 𝑃P and 𝑃′P′) is that we can always travel from the last node in 𝑃P to the first node in 𝑃′P′, because an edge between them must be present in either 𝐺G or 𝐺′G′.

Problem CF-2056F1

Statement

A sequence 𝑎a of 𝑛n integers is called good iff the following condition holds:

  • Let 𝑐𝑛𝑡𝑥cntx be the number of occurrences of 𝑥x in the sequence 𝑎a.
  • For all pairs 0 ≤𝑖 <𝑗 <𝑚0≤i<j<m, at least one of the following must be true:
    • 𝑐𝑛𝑡𝑖 =0cnti=0
    • 𝑐𝑛𝑡𝑗 =0cntj=0
    • 𝑐𝑛𝑡𝑖 ≤𝑐𝑛𝑡𝑗cnti≤cntj

In other words, if both 𝑖i and 𝑗j are present in the sequence, then the number of occurrences of 𝑖i must be less than or equal to the number of occurrences of 𝑗j.

You are given integers 𝑛n and 𝑚m. Compute the bitwise XOR of the medians of all good sequences 𝑎a of length 𝑛n, where each element 𝑎𝑖ai satisfies 0 ≤𝑎𝑖 <𝑚0≤ai<m.

Constraints:

  • 𝑛 ≤2200n≤2200 (given to us in its binary form)
  • 𝑚 ≤500m≤500

Solution

A reasonable (and probably the only immediately obvious) direction to take is to fix the median and then consider the set of good sequences that correspond to that median, as 𝑚m is conveniently sized.

Clearly, for a fixed median 𝑞q, the only thing that matters is the number of sequences having their median as 𝑞q. If this number is even, 𝑞q has a no contribution at all to the overall answer. A potential solution then begins to take form in one's mind:

  • Iterate over 𝑞q.
  • Find the parity of the number of good sequences with 𝑞q as their median.
  • If the aforementioned value is odd, include 𝑞q within the final set of terms to be XORed to get the answer.

Let's define two functions for convenience:

  • cnt(𝑞)cnt(q): The number of good sequences with 𝑞q as their median.
  • par(𝑥) =(𝑥mod 2)par(x)=(xmod2).

A very brief consideration should reveal to one the huge difference in computational difficulty between the analysis of cnt(𝑞)cnt(q), and par(cnt(𝑞))par(cnt(q)), but the latter will still require some basic ideas from the former, so let’s go through them.

Let’s partition all sequences with median 𝑞q into maximal groups that have the same multisets. These groups are obviously mutually exclusive and exhaustive. This makes analysis of all the sequences much easier, as the number of sequences that correspond to a single multiset 𝑀M is simply: 𝑛!∏𝑥∈𝑆(𝑀)freq𝑀(𝑥)!n!∏x∈S(M)freqM(x)! (where 𝑆(𝑀)S(M) is the set of unique elements in a multiset 𝑀M, and freq𝑀(𝑥)freqM(x) is the number of occurrences of 𝑥x in 𝑀M)

Now, it's not difficult to see this expression and guess that it's a bit difficult to get it to be odd (ie. it is even for most partitions of 𝑛n). If we can discover some necessary/sufficient conditions for it to be odd, we can simply ignore the groups of sequences corresponding to all multisets for which said conditions aren't satisfied (as they have no contribution to the final parity).

Let 𝑡(𝑥)t(x) be the highest 𝑦y such that 2𝑦 ∣𝑥2y∣x.

For the aforementioned expression to be odd, we require 𝑡(𝑛!) =∑𝑥∈𝑆(𝑀)𝑡(freq𝑀(𝑥)!)t(n!)=∑x∈S(M)t(freqM(x)!). Since the set of frequencies is always a partition of 𝑛n, let's reduce the problem to the following:

When does a partition 𝑆S of an integer 𝑛n have 𝑡(𝑛!) =∑𝑥∈𝑆𝑡(𝑥!)t(n!)=∑x∈St(x!)?

Let's focus on 𝑡(𝑥!)t(x!) for arbitrary 𝑥x. It's not difficult to arrive at: 𝑡(𝑥!)=⌈log2⁡(𝑥)⌉∑𝑏=1⌊𝑥2𝑏⌋t(x!)=∑b=1⌈log2⁡(x)⌉⌊x2b⌋ This definition, while pretty concise, doesn't really get us all the way to a point where we're able to state meaningful assertions about the difference between 𝑡(𝑛!)t(n!) and ∑𝑥∈𝑆𝑡(𝑥!)∑x∈St(x!), so let's try to rewrite it in a more helpful manner.

It shouldn't seem too unmotivated of a directional change when we now consider the binary representations of the numbers involved here (division by 2 is a right shift, we're dealing with huge numbers, etc.): We reinterpret the expression described before by considering the contribution of each bit in the binary representation of 𝑥x to 𝑡(𝑥!)t(x!), and realize that a set bit at the 𝑏b-th position in the binary representation of 𝑥x contributes ∑𝑏−1𝑖=02𝑖 =2𝑏 −1∑i=0b−12i=2b−1 to 𝑡(𝑥!)t(x!). Summing this up over all set bits 𝑏b yields a beautifully convenient expression!: 𝑡(𝑥!) =𝑥 −𝑏(𝑥)t(x!)=x−b(x), where 𝑏(𝑥)b(x) is the number of set bits in the binary representation of 𝑥x.

The comparison of 𝑡(𝑛!)t(n!) to ∑𝑥∈𝑆𝑡(𝑥!)∑x∈St(x!) now simply reduces to comparing 𝑏(𝑛)b(n) and ∑𝑥∈𝑆𝑏(𝑥)∑x∈Sb(x). ∑𝑥∈𝑆𝑏(𝑥) ≥𝑏(𝑛)∑x∈Sb(x)≥b(n) holds trivially, but we require them to be equal. It's easy to show that ∑𝑥∈𝑆𝑏(𝑥) =𝑏(𝑛)∑x∈Sb(x)=b(n) holds iff every set bit in 𝑛n is set in exactly one element of 𝑆S, and the proof is left as an exercise to the reader.

We finally have a result we can use:

𝑛!∏𝑥∈𝑆x!n!∏x∈Sx! (where all elements in multiset 𝑆S sum to 𝑛n) is odd ⟺ ⟺ No two elements of 𝑆S have a common set bit

This implies that any "good" additive partition 𝑆S of 𝑛n is also a clean "Bitwise-OR partition". It also follows that 𝑆S can have no duplicate elements.

We now make the following key observation:

There is a unique maximum element in 𝑆S, and it is ≥𝑛/2≥n/2 (since the most significant bit of 𝑛n is set in exactly one element of 𝑆S).

Let us return to the problem at hand. To recap, we:

  • Fixed median 𝑞q.
  • Fixed a multiset 𝑀M with median 𝑞q and analyzed all sequences that correspond to this multiset.

Now, how does our result help us here? Well:

  • We now only care about multisets whose "frequency set" constitutes a good partition of 𝑛n (We will call a multiset good if it's frequency set is good).
  • We're relieved of the responsibility of having to force 𝑞q to be the median, since exactly one element has a frequency ≥𝑛/2≥n/2 in a good multiset and is indisputably the median. This element must obviously be 𝑞q.

For a fixed 𝑞q, all the sequences that correspond to a fixed, good multiset have a collective contribution of exactly 11 to our answer, so for any fixed 𝑞q, we simply have to find the number of good multisets, and if this number is odd, include 𝑞q within the final xor sum that is our answer.

How do we find the parity of the number of good multisets with median 𝑞q?

This is a very simple sub-problem that can be solved with the help of dynamic programming:

  • Define 𝑓(𝑖,𝑗)f(i,j) to be the parity of the number of ways to partition a sequence of length 𝑖i into 𝑗j non-empty subsequences. Compute all 𝑓(𝑖,𝑗)f(i,j) for 𝑖,𝑗 ≤𝑘i,j≤k (where 𝑘k is the number of set bits in 𝑛n) in 𝑂(𝑘2)O(k2) (using the transition 𝑓(𝑖,𝑗) =((𝑓(𝑖 −1,𝑗 −1) +𝑓(𝑖 −1,𝑗) ⋅𝑗)mod 2)f(i,j)=((f(i−1,j−1)+f(i−1,j)⋅j)mod2)).
  • Then, we iterate over the number of unique elements, 𝑥x, in our good multiset. The contribution of the number of good multisets with 𝑥x unique elements shall be (𝑞𝑥−1) ⋅𝑓(𝑏(𝑛),𝑥)(qx−1)⋅f(b(n),x). We now apply our previously derived result again and realize that the parity of (𝑞𝑥−1)(qx−1) is 1 if and only if (𝑞 −𝑥 +1) ⊕(𝑥 −1) =𝑞(q−x+1)⊕(x−1)=q (where ⊕⊕ is the bitwise-XOR operator), and add the parity of this expression to our answer.

We therefore compute this parity for every median 𝑞q in 𝑂(𝑘2)O(k2) time, and XOR the answer with 𝑞q in the case of said parity being 1. This is an 𝑂(𝑚 ⋅𝑘2)O(m⋅k2) solution, which fits within the problem's T/M-L.

We can however, make our solution faster by simply precomputing the dynamic programming states, which brings the time complexity of our solution down to 𝑂(𝑘2 +𝑚 ⋅𝑘)O(k2+m⋅k).

The code ends up being rather simple, and has been included below.

#include<bits/stdc++.h>
using namespace std;

const int K = 205;

int dp[K][K];

signed main()
{
    ios_base::sync_with_stdio(false), cin.tie(NULL);

    dp[0][0] = 1;
    for(int i = 1; i < K; i ++)
    {
        for(int j = 0; j < i; j ++)
            dp[i][j + 1] += dp[i - 1][j], dp[i][j] += dp[i - 1][j] * j;
        for(int j = 0; j <= i; j ++)
            dp[i][j] &= 1;
    }

    int t = 1;
    cin >> t;
    while(t --)
    {
        int k, m;
        cin >> k >> m;

        vector<char> n(k);
        for(int i = k - 1; i >= 0; i --)
            cin >> n[i];

        int b = count(n.begin(), n.end(), '1');

        int ans = 0;
        for(int med = 0; med < m; med ++)
        {
            int cnt = 0;
            for(int x = 1; x <= min(b, med + 1); x ++)
                if(((x - 1) ^ (med - (x - 1))) == med)
                    cnt += dp[b][x];

            ans ^= ((cnt & 1) * med);
        }

        cout << ans << endl;
    }
}
